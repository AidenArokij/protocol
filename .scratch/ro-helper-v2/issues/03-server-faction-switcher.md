# 03: Иконки серверов и быстрый выбор сервера и фракции

**What to build:** В шапке окна поиска — плашка «иконка сервера · Сервер · Фракция». По нажатию раскрывается выбор: три сервера с иконками и цветами с вики и сетка организаций выбранного сервера со значками. Выбор применяется сразу, без «Сохранить». Первый запуск и настройки используют те же иконки.
