# 30: Версия пакета и отпечатки статей (roadmap 1Б)

**What to build:** Понятная человеку версия законов и отпечатки статей — основа для снимка базы у «Дел»
(этап 5) и для кэша проверенных ответов ИИ (этап 3).

**Decisions:**
- Версия и отпечатки вычисляются из пакета на лету (`src/core/snapshot.ts`), а не пишутся импортом: пакеты не растут (в Тверском 3266 статей), `PACK_FORMAT` и импорт не меняются, старые копии ничего не замечают. В ADR 0003 и roadmap было «импорт пишет `label`» — поправить в ветке `docs-roadmap`.
- Версия — день сборки пакета по Москве («2026.9.30»); два пакета одного дня читаются одинаково, для приложения их различает `built`.

**Who:** skyze's agent.

**Blocked by:** —

**Status:** done

Сделано: `packLabel`, `articleFingerprint` (FNV-1a по названию, тексту, наказаниям и примечаниям), `snapshotOf`, `changedSince` с тестами (в т.ч. отпечатки не совпадают у статей с разным текстом по всему Тверскому); строка «Версия законов» в «Настройки» → «Законы». Читателей у снимка пока нет — их добавит этап «Дела».

Заодно: сохранённые закрепления больше не затирают карточку, закреплённую, пока они читались (калькулятор из быстрого поиска сразу после запуска) — тест #23 изредка зависал на этом.
