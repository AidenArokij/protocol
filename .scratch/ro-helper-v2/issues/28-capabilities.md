# 28: Профиль организации и права (roadmap 1А)

**What to build:** Одна модель «кто что может»: чистая функция `capabilitiesOf` в `src/account/capabilities.ts`
собирает права из входа, ролей, админа и организации; интерфейс спрашивает право, а не «лидер ли это». Условия
вида `organization.id === 'none'` заменяются на «это фракция» по данным пакета. ADR: `docs/adr/0001-organization-profile-and-capabilities.md`.

**Decisions (owner, 01.10.2026):**
- Организация ничего не закрывает — только меняет, что показано первым; закрывают вход, роли и админ.
- Поля профиля организации появляются только вместе с тем, кто их читает (учебные наборы — этап 6А, быстрые действия — 2В).
- Права ИИ (`ai.server`) — на этапе 4, когда сервер ИИ станет их проверять.

**Who:** skyze's agent.

**Blocked by:** —

**Status:** done

Сделано: `src/account/capabilities.ts` (`Capability`, `capabilitiesOf`, `isFaction`) с тестами по каждой строке таблицы профилей; `useCapabilities()` в `src/ui/roles.tsx`. На права переведены: раздел администратора, панель лидера, заявка на лидера, памятки (писать, удалять чужие). Проверки `organization.id === 'none'` заменены на `isFaction` (организация с `kind`).
