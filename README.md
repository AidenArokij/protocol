# MVD Helper — памятка МВД поверх игры

Окно с памяткой поверх игры, открывается и прячется на **F9**. Внутри:

- **Разбор** — описываете ситуацию своими словами, приложение разбивает её на эпизоды и к каждому подбирает статьи, санкции и порядок действий;
- **Статьи** — поиск по УК, КоАП, УПК, 6-ФЗ, Уставу и другим законам;
- **Памятка** — кодексы, работа с гражданскими, устав;
- **Миранда** — текст прав при задержании с подстановкой фамилии и статьи, кнопка «Скопировать».

Игра должна быть запущена **в окне или без рамки**, иначе окно поверх неё не видно.

---

## 1. Первая сборка (один раз)

1. Зарегистрируйтесь на https://github.com.
2. Справа вверху **+ → New repository**. Название, например, `mvd-helper`. Тип **Public**: приложение скачивает базу из публичного репозитория. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**. Перетащите в окно **содержимое** распакованного архива (папки `src`, `src-tauri`, `.github` и файлы `package.json`, `app-icon.png`, `README.md`), затем **Commit changes**.
   - Если папка `.github` не загрузилась (Windows её иногда скрывает): **Add file → Create new file**, в имени файла наберите `.github/workflows/build.yml` и вставьте содержимое этого файла из архива.
4. Откройте `src/config.js` → значок карандаша → замените `ВАШ_НИК/mvd-helper` на свой адрес, например `ivanov/mvd-helper` → **Commit changes**.
5. Вкладка **Actions** → слева **Сборка установщика** → **Run workflow**. Сборка идёт 10–15 минут.
6. Когда появится зелёная галочка: на главной странице репозитория справа **Releases** → скачать `MVD Helper_1.0.0_x64-setup.exe`.

Эту ссылку на Releases и раздаёте фракции.

## 2. Как обновлять законодательную базу

Переустанавливать приложение **не нужно**. Приложение при каждом запуске скачивает базу с GitHub (есть и кнопка «Обновить» в шапке). Если интернета нет, работает последняя скачанная копия.

- Статьи: `src/data/laws.json`
- Ситуации для разбора: `src/data/situations.json`

Открыть файл на GitHub → карандаш → правка → **Commit changes**. В шапке файла поменяйте `"updated"` на текущую дату — её видно в приложении, чтобы все понимали, какая у них версия базы.

### Формат статьи (`laws.json`)

```json
{
  "code": "УК",
  "num": "105",
  "title": "Неповиновение законному требованию",
  "tags": "неповиновение требование отказ",
  "text": "Краткое содержание статьи",
  "sanction": "Штраф до 40.000 либо 30 мес.",
  "full": "Необязательно: полный текст статьи"
}
```

`tags` — слова, по которым статью будет проще найти. `full` — полный текст, показывается под спойлером.

### Формат ситуации (`situations.json`)

```json
{
  "title": "Не предъявляет документы",
  "keys": ["документы", "паспорт", "не показывает"],
  "verdict": "uk",
  "articles": ["6-ФЗ-13 п.2", "УК-105"],
  "steps": ["Назвать основание", "Повторить требование", "Отказ — задержание по ст.105"],
  "notes": ["Если основания не было — неповиновения тоже нет"]
}
```

- `keys` — слова и фразы, по которым ситуация распознаётся. Фраза срабатывает, если в описании есть все её слова, в любой форме.
- `verdict` — `uk` (УК), `koap` (КоАП), `ok` (не нарушение), `proc` (процедура).
- `articles` — ссылки на статьи в виде `КОД-НОМЕР`, как в `laws.json` (например `КоАП-8.12`).

Там же есть блоки `flags` (оговорки: госслужащий, группа, жилище) и `synonyms` (группы слов, которые считаются одинаковыми: «ствол», «пистолет», «оружие»).

**Важно:** JSON чувствителен к запятым и кавычкам. После правки проверьте файл на https://jsonlint.com. Если файл сломан, приложение не примет его и продолжит работать на предыдущей копии.

## 3. Новая версия самого приложения

Нужна только при изменении интерфейса или кода, для законов не нужна. Поменяйте `"version"` в `src-tauri/tauri.conf.json` и `package.json` (например на `1.0.1`) и снова запустите **Actions → Run workflow**.
